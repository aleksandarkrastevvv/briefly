# User Stories

## Reader

- As a reader, I want to start today’s brief so I can understand the day quickly.
- As a reader, I want a finishable sequence so I do not feel trapped in an endless feed.
- As a reader, I want three key points so I can scan the story fast.
- As a reader, I want original sources so I can verify claims.
- As a reader, I want to ask questions so I can understand unfamiliar topics.
- As a reader, I want “what this means for me” so I can see practical relevance.

## Editor

- As an editor, I want to manage sources so ingestion stays transparent.
- As an editor, I want to review clusters so AI mistakes do not publish directly.
- As an editor, I want to reorder the daily brief so editorial judgment remains in control.

## Operator

- As an operator, I want ingestion logs so failures are visible.
- As an operator, I want safe failure states so bad data does not become public content.
