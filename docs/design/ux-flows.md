# UX Flows

## Daily Brief

1. User lands on Home.
2. User sees greeting, date, market, story count and reading time.
3. User starts or continues the brief.
4. User moves story by story.
5. User can save, share or open full story.
6. User reaches completion state.

## Market Switching

1. User selects market.
2. App updates language, stories, sources and progress.
3. Market data remains separated.

## Personalisation

1. User opens profile card.
2. User selects lightweight context.
3. App uses context for “what this means for me.”
4. User can delete profile data.

## Source Management

1. Editor enters source record.
2. New source remains inactive until verified.
3. Ingestion can only run against active configured sources.

## AI Q&A

1. User opens full story.
2. User chooses suggested question or writes one.
3. System answers only from linked story sources.
4. System refuses when source support is insufficient.
5. User can rate answer usefulness.
