# Design System

## Direction

Briefly should feel like a premium consumer product, not a news portal or admin dashboard.

## Principles

- mobile first
- calm neutral base
- one distinctive accent
- strong editorial typography
- generous spacing
- high contrast
- minimal visual noise
- no endless-feed feeling on Home

## Current Tokens

The static foundation defines tokens in `styles.css`:

- color
- spacing
- radius
- shadow
- animation

## Component Priorities

- Wordmark
- Market switcher
- Home hero
- Daily Brief progress
- Story card
- Full story sections
- Source list
- Profile chips
- AI Studio social cards

## QA Rules

- Text must not overflow buttons or cards.
- Cards must keep stable dimensions.
- Mobile layout is the primary layout.
- Reduced motion must be respected.
- Social assets must contain useful information, not only teasers.
